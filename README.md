# Med Finder Ethiopia

A web platform that helps users **search for medicines**, **check availability at nearby pharmacies**, and **manage prescriptions** easily in Ethiopia.

## Project Overview

Med Finder Ethiopia allows users to quickly find medicines, see which pharmacies have them in stock, and manage their prescriptions online.  
The platform features a **clean and responsive design**, real-time stock updates, and location-based pharmacy availability, making it easier for users to access essential healthcare products.

This project demonstrates skills in **full-stack development, frontend design, backend APIs, and database management**.

---

## Features

- Search for medicines by name or category  
- View availability across nearby pharmacies  
- Add medicines to a favorites list for quick access  
- Submit and manage prescriptions online  
- Real-time updates on stock and pharmacy locations  

---

## Technologies Used

- React.js  
- Tailwind CSS  
- Node.js  
- Express.js  
- MongoDB
