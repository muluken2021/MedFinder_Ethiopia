# MedFinder Ethiopia

MedFinder Ethiopia is a web-based platform currently under development. It aims to help people easily find where a specific medicine is available nearby. Pharmacies across Ethiopia can register and list their medicines, while users can search by name, check availability, and contact pharmacies directly.

## Overview

In Ethiopia, many patients face challenges finding specific medicines across different pharmacies. MedFinder Ethiopia addresses this issue by connecting users and pharmacies through a centralized and user-friendly system.

Users can:
- Search for medicines by name.
- View pharmacies that have the medicine in stock.
- Check pharmacy details and contact information.

Pharmacies can:
- Register and manage their medicine inventory.
- Access a personal dashboard to track listed medicines and availability.

Admins can:
- Manage all registered pharmacies.
- Verify listings and maintain system accuracy.

## Key Features

- Medicine search by name or brand
- Pharmacy registration and management
- Pharmacy dashboard for inventory control
- Admin dashboard for system monitoring
- Responsive and modern user interface
- Secure authentication system

## Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB 
- Authentication: JWT (JSON Web Token)
